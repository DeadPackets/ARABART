Quick Cleaner:

The quick cleaner is designed to allow you to quickly get rid of those junk files stored every where in your memory wasting valuable space.

How do I choose what to be cleaned?
By clicking the check boxes beside each cleaner category you turn this category ON or OFF.

What is "scan"?
Once you are done selecting what cleaning categories you want MemMaid to do, tap on the [scan] button, this will make MemMaid scan your memory and report the size of the items it found. Scan doesn't delete the files. If you want to know more details about the files found by MemMaid, switch to the Advanced Cleaner

How do I clean?
Once you are done selecting what Cleaning Categories you want MemMaid to do, tap on the [clean] button, this will make MemMaid scan your memory for junk files and delete them and then report the size of the items it cleaned. If you want to know more details about the files found by MemMaid, switch to the Advanced Cleaner

What are the cleaning categories?
These items define the clean criteria you want MemMaid to use, to give you great flexibility in configuring MemMaid Cleaner.
Example: You can select to delete the PIE Cache files but not the PIE cookies.

Are there any other options for the cleaner?
The cleaner can be configured through the Cleaner Options dialog

Reclaim RAM:
MemMaid can retrieve RAM that is currently used by running programs. Results may vary depending on your device. It can be from few KB up to several MBs

How do I use it?
There are two possible ways.
From within MemMaid’s cleaning tab, switch to the "ReclaimRAM" view, select your desired options and then tap on the [Reclaim] button.
MemMaid will display how many bytes were claimed.
You can also us the ReclaimRAM shortcut in the programs folder or assign it to a hardware button and use it whenever you run low on memory without opening MemMaid.

Will I loose any data if I use ReclaimRAM?
No, because MemMaid uses a standard Windows Mobile procedure for claiming this memory. However some applications that are not designed to handle this procedure may not respond properly

What are the different options in the ReclaimRAM?
Free unused program memory: Sends messages to running programs to free their unused memory.
Compact Heap: Compact and optimize the memory used by running processes.
Close Running Programs: Close running programs (except MemMaid and ActiveSync).

Cleaner Options:

MemMaid gives you the ability to have two custom directories to be cleaned. You can setup up those directories to point to any third part application cache directory and MemMaid will clean it for you.
(Please note: MemMaid will delete all the files and subdirectories in this directory so please make sure it’s safe to do so before using it)

Custom Files:
MemMaid can search your memory for files with specific extensions and clean them (Those files usually are backup files or temporary files).
MemMaid has a preset list for *.tmp, *.bak, *.log and a 4th one to allow you to specify your own extension.
Turn ON the extensions you want MemMaid to clean for you.
(Please make sure the extension you enter is used for a junk files you want to get rid of)

Ignore references to external cards:
Use this feature to tell MemMaid to ignore references to external cards.
If you have multiple external memory cards which you switch among them or have one that is not inserted while cleaning you might want to turn this feature ON.

Secure File delete (wipe):
Normal file delete will only mark the files deleted. While this cleaned memory is available to be used by other programs, these files can get “undeleted” using special programs.
By turning this option ON those files will be wiped out totally without a chance for them to be undeleted again.

Close PIE before cleaning:
Turning this feature ON gives MemMaid more control over cache directories and files.

Notification Queue:

What is the notification queue?
The notification queue is a special database of events and programs registered to run at those events (alarms, reminders, card insertion, USB connection …etc)

Why do I need to clean this database?
For some reasons some programs get registered for the same event more than one time. Those duplicate entries slow down your device and that’s why it’s better to find and delete them
Also some other programs register themselves for some events and when you uninstall those programs they leave behind those registrations

How do I find the duplicate entries?
MemMaid can, tap on the [find] button and select the find criteria.
MemMaid can find duplicate, dangling, expired or invalid notifications also using the “Find…” option you can search the notifications by type or program name
How do I delete notification entries?
By clicking the [delete] button all the marked entries will be deleted

Is it safe to delete any event?
No, please delete only the duplicates or the entries you know for sure you don’t want
Deleting important entries might cause your device to not function probably

Can I add my own notification?
Yes, MemMaid gives you the ability to add your own notification, tap [Add] and then fill your notification parameters
The application you select will run at the event or time you choose
Using the arrow beside the [Add] button will bring a special command menu allowing you to re-build the notification queue or create the ActiveSync notification queue entries

Extensions:

This screen lists all the registered extensions and their file types along with information about the default program the system uses for handling this file type

Can I delete an entry?
Yes, you can delete any entry by selecting it and using the [delete] button, once you delete an entry this will make the delete file type unknown to the file system and when you tap on a file from this type in the file explorer the system won't be able to open it, also the default icon used for this program will be the "unknown" icon shape

When I tap [Edit] I'm asked to choose (association or class) what are those?
The association is assigning an extension to a file type class
While editing the association, you can assign an extension to a different class or use a new one
The class describes how the system handles the file extension assigned to it, the class will have different commands, and the default mandatory command is the “open” command which is used to open the file when you tap on it in the file explorer
While editing the class, you can add, remove, edit commands for this file

How can I create an association?
Tap on the [Add] button and type the extension and the class (file type name) you want to handle this extension
If you choose to use a new class type, then MemMaid will ask you for the "open" command parameters. If you select an existing class (file type) then MemMaid will show you the current configuration for this class in case you want to change it

Start Up Services:

This tab shows you the list of services which run with the system start (After a Soft Reset)

Can I delete any of those services?
No, MemMaid doesn’t allow you to do that because you can easily make the system unusable if you remove some of the essential services.

How can I add a new service?
This is usually done by setup applications (if they need to do so).

Can I change the running order?
No, the order is determined by the system as some of the services depend on other services.

Can I stop/start services manually?
Yes, you can stop/start services using the stop/play buttons (the ones with the square and triangle shapes) or you can tap on the green button beside the program name to toggle its status
Green icon beside the program means this service is active (running) and a gray icon means this service is inactive (not running)
Please note that, disabling a service will not prevent it from starting again when the system restarts if it’s set to automatically start (unless you switch it to manual start using the “options” button)

What are the options available for startup services?
Startup services can be run manually or automatically, usually this is something the installing program decides
Auto Start: Means this service will start automatically with the system
Manual Start: Means this service doesn’t start with the system and there has to be another program starting manually when needed

Today Plug-ins are special programs which display information right into your today screen. (Example, Date, Calendar, tasks …etc)

Why would I need to delete a plug-in?
Some plug-ins leave information about themselves even after you completely uninstall them, those entries in the registry are useless and deleting them will make the registry cleaner. To help you identify those bad data, MemMaid will mark them with a different color.

Green icon beside the today plug-ins means that the today plug-in is active (running) and a gray icon means this today plug-in is inactive (not running)
Please note that, disabling a today plug-in will prevent it from starting again when the system restarts (until you activate it again from MemMaid)
Click on the icon beside the plug-in name in the list to enable/disable
Green means ON and grey means OFF

How can I arrange the today plug-ins?
Select the plug-in you want to move and click on the buttons with the top and down arrows

How can I add new plug-ins?
The only way to add today plug-ins is to install new ones
Today plug-ins setup will add them to the list

Memory Tweaks:

MemMaid gives you the ability to change some system settings (tweaks) to get better memory utilization.
(Please note: changing any of these tweaks will not take effect until you tap [apply] and allow MemMaid to Soft Reset your device.

If you're not sure how to use the tweaks, then let MemMaid decides for you, just tap on the [optimize] button and select your optimization criteria and let MemMaid do the work for you

Those tweaks are:

* PIE Cache Size Limit
The size limit of the cache directory used by PIE

* PIE Reading Buffer
The buffer size that PIE uses for reading the website pages you're loading

* PIE History Size
The max number of history entries before PIE starts cycling through them

* PIE Max Connections
The number of connections PIE can use at the same time to access the website you're surfing

* Opera Cache Size
The size limit of the cache directory used by Opera

* Opera Download directory
Change the directory Opera downloads files to

* File system cache size
The memory used to cache the file system operations

* Font cache size
The memory used to cache the fonts used in the system

* SD/MMC Transfer
The size of the memory buffer used in the data transfer to and from your SD card

* Animate windows
When you open a new window, do the system use animation or not

* Animate Menus
When you open a menu, do the system use animation or not

* Clean program history on Soft Reset
Do you want MemMaid to clean the last used programs every Soft Reset or not

* TCP Window
The size of the TCP window, used for any network communications

DLL Optimizer:

What is the DLL Optimizer?
The most important part of your PocketPC’s memory is the main memory as it contributes directly to the speed and performance of your PocketPC. The more free memory you have in the main memory the faster your PocketPC is.
This feature allows you to move some program DLLs (extensions) from the main memory to other less important storage memory types. (Like built-in storage, iPaq-file-store, SD Card, CF Card …etc).

How do I use the DLL Optimizer?
The first thing you need to do is to enable this feature. Go to the “DLL optimizer” screen in the Memory Tweak tab. If the button there says [enable] you’ll need to tab on this button to enable this feature. If the button there says [disable] this means this feature is already enabled.

Now, which DLLs should I move?
The DLLs listed in the left hand side depend on your PocketPC and the programs installed in it. The DLLs listed there in a green color are reported by users to be safe to move.
The Yellow DLLs are today-plugin DLLs (today plugins usually prefer to be installed on the main memory, however, they might work fine in your device if you move them)
You can try to move other non-green DLLs listed there as well but you’ll have to make sure that the programs they belong to are still working fine. So, before moving DLLs make sure to check the info window below the DLL list, when a DLL is selected, this window will display information about it including the program it belongs to.

What if I move a DLL and its program is not working?
You can move the DLL to a different memory type and try again. If the program insists to have its DLL in the main memory so maybe it’s a good idea to leave this DLL in the main memory. (Note: you’ll need to move any DLL back to the main memory before trying to move it to any other memory type).

How would uninstalling programs work with this?
The uninstall program will try to remove installed DLL from where it was installed the first place, Using this feature might confuse uninstall programs. So before uninstalling any application please make sure to move its moved DLLS back to the main memory.

What happens when I disable this feature?
When you disable this feature, MemMaid will move all the moved DLLs back to the main memory.

Look & Feel:

The look & feel dialog gives you a chance to slightly change the way MemMaid looks to suite your taste.
You can choose from the different background styles and button styles
You can also override the default colors for
  • Background highlight
  • Buttons highlight
  • Title text
  • Controls text
Once you turn on the check box beside the entry, the button besides it gets enabled allowing you to use it to select a different color.

Program Settings:

This window allows you to view and change MemMaid settings

- Turn ON/OFF the confirmation message before MemMaid soft-resets (reboots) your system.

- Turn ON/OFF the statistics message that shows up when you use ReclaimRAM shortcut (from outside MemMaid).

- Turn ON/OFF the ability to make MemMaid remember the last used tab.

- Turn ON/OFF the ability to make MemMaid remember the last used screen in each tab.

- Turn ON/OFF the advanced mode. When this feature is OFF MemMaid will run at the protected mode allowing you to only execute the commands known to be safe for your device.
