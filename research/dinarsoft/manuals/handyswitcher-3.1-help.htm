Shortcuts

HandySwitcher installs several shortcuts (icons).
The main shortcut is named HandySwitcher and is installed in the main programs folder, the other shortcuts are created in a subfolder under the programs folder named "HandySwitcher Actions".

Each shortcut of those can be assigned to a hardware button (go to Start->Settings->Buttons and select the button you want to use and then from the drop down menu find the HandySwitcher action you want to assign to it).

The main shortcut "HandySwitcher", runs HandySwitcher while if HandySwitcher is already running, using this shortcut will show HandySwitcher's menu.
The other shortcuts are named as HandySwitcher followed by the action name between square brackets.

Shortcuts are:
  • HandySwitcher [OK-Close] to close the active program.
  • HandySwitcher [Minimize] to minimize the active program.
  • HandySwitcher [Close All] to close all running programs.
  • HandySwitcher [Close All But Active] to close all the programs running in the background.
  • HandySwitcher [Minimize All] to minimize all running programs.
  • HandySwitcher [Activate Next] to switch to the next running program (similar to alt-tab on the desktop PC).

Menu
 HandySwitcher's menu shows a list of the running programs along with a list of actions (like Close all, CPU usage ...etc). HandySwitcher shows only the running programs which are not in the Ignore List

To activate a program in the list, just tap on the program's name.
To close a program in the list, just tap on the [X/OK] button beside the program name. Please note that the [X/OK] button beside each program does a force-close, so even if a program is in the Minimize List or System default list, it will also be closed.
The list of actions below the list of running programs are configurable, you can add or remove from them through the Menu Items dialog.

Hardware keys support
While the menu is displayed you can use your D-Pad to completely control your HandySwitcher functions.
- Use the up/down buttons to navigate through the menu items.
- Use the left direction key, to close the menu.
- Use the action button, to activate the selected program or execute the selected action.
- Use the right direction key, to close the select program.

If you want to use hardware keys to bring up HandySwitcher's menu then you need to assign a hardware button to HandySwitcher's shortcut.
For more information about HandySwitcher's shortcuts and hardware button assignment visit the shortcuts section

CPU Usage

This dialog shows you a list of all the running processes in the system. Along with the executable name, you'll see CPU percentage used. This dialog refreshes dynamically to provide most up-to-date information.

Can I change the sorting?
You can sort by CPU usage or by process name by tapping on the header.
Tapping on the header again will reverse the sort order.

What is the "Include the calculation time"?
This option allows include/exclude the time taken to gather and calculate the CPU usage data. (This time is added to the services.exe as HandySwitcher is running as a service.)

What is the "Memory >" button?
HandySwitcher has another dialog that provides you with the memory allocated by each process; you can switch to the memory usage dialog using this button.

Memory Usage

This dialog shows a list of all the running processes in the system. For each process, the executable name and memory used are shown. This dialog will not-refresh dynamically as the memory usage calculations is a bit long process on some devices.

Can I change the sorting?
You can sort by memory usage or by process name by tapping on the header. Tapping on the header again reverses the sort order.

How can I update the memory usage information?
Using the [refresh] button you can force HandySwitcher to update its data and re-calculate the memory usage for each process.

Can I terminate any running process?
HandySwitcher gives you the ability to terminate any running process by selecting the process and then using the [terminate] button. However, not every process can be terminated safely. HandySwitcher warns before terminating any process and if the process is crucial, a second warning is shown.

What is the "CPU >" button?
HandySwitcher has another dialog that provides you with the CPU percentage used by each process, you can switch to the CPU usage dialog using this button.

Actions

HandySwitcher takes control of the (OK / X) button on your top-right hand corner to change its functionality to suite your needs.
This is optional as you can disable HandySwitcher’s handling of the (OK / X) by remove the check mark beside the “OK / X Button” option.

What are the different actions that I can assign to the (X) Button?
The default action in the Windows Mobile operating system is to smart-minimize the active program when you tap on the (X) button. With HandySwitcher, you can change this behaviour and assign a different action to tap-and-hold on the (X) button.
The actions that you can assign to tap and tap-and-hold are
  • Close: HandySwitcher will try to close the active program.
  • Minimize: HandySwitcher will minimize the active program
  • MinimizeAll: HandySwitcher will minimize all running programs taking you directly to the today screen.
  • CloseAll: HandySwitcher will try to close all running programs.
  • ShowMenu: HandySwitcher will display its menu.
  • Close All But Active: HandySwitcher will try to close all the background running programs (giving the active program more memory and CPU power to use).
  • SystemDefault: HandySwitcher will ask the system to do the normal smart-minimize action to the active program (This might close or minimize the active program

What is the “(OK) Hardware button support”?
You should use this feature only if your device is equipped with an (OK) hardware key or you have assigned a hardware key to the system <OK/Close> action.
Once this feature is enabled, HandySwitcher will take over the handling of this button from the system allowing you to close (not just minimize) the active program when you press this button.


Can HandySwitcher start with the system?
Yes, while in the options dialog, tap on the [file] menu/softkey at the bottom, and enable or disable the start with the system menu item.

How do I exit HandySwitcher?
While in the options dialog, tap on the [file] menu/softkey at the bottom, and select "Exit HandySwitcher".

Special and Automation List

This is a list of special commands which HandySwitcher can automate for you along with an advanced ignore list.
Ignore list is a list of program which HandySwitcher will treat them different the rest of the programs. HandySwitcher provides a very advanced ignore list which allows you to customize HandySwitcher’s behaviour towards running program the way you like.

To add an program to the ignore/minimize/system default lists, you just simply tap on the [+] button beside the list, this will take you to another screen where you can select the action you want HandySwitcher to do and assign it to one of the programs in the list.
Important: Make sure to have the program you want to add running when you try to add it.
To remove programs from the ignore list, simply select the program and tap on the [-] button.

What are the different actions that I can assign to a certain program?
There are several actions you can use
  • Ignore List Programs in the ignore list will not show in HandySwitcher's menu and whenever you tap on the (OK/X) button at the top HandySwitcher will send your request to the system.
  • System Default This is a different flavour of the "ignore list" as HandySwitcher will send all your requests for this program to the system. However, unlike the "ignore list" the programs in this list will show in HandySwitcher's menu allowing you to switch to them and force-close them using the [X] button beside their names in the menu.
  • Minimize List HandySwitcher will always try to minimize the programs in this list unless they have an (OK) button at the top-right and not an (X) button. You can switch to those programs through the menu or force-close them using the [X] button beside their names in the menu.
  • Automation This is actually not an ignore list per say but a special list of commands HandySwitcher can automate for you, those commands are
    • Close ActiveSync on disconnect When you add this to the list, HandySwitcher will automatically close ActiveSync on your behalf whenever ActiveSync disconnects. This is a great way to save memory, battery and CPU power as HandySwitcher will close ActiveSync whenever it’s not needed anymore. (please note: This feature is available only on WM5 and above). On the next connection, ActiveSync will run automatically again. 
    • Reclaim RAM on close A great way to increase the free memory whenever you close a running program.
    • Compact Memory on close all Whenever you ask HandySwitcher to close all the programs HandySwitcher will close them and ask the operating system to clean out the whole memory for you.
Can I move one item in the list between different commands?
To do this you’ll need to remove the item and then add it again in with the new required action.

What is this option for “confirmation”?
Some programs do not respond to HandySwitcher’s request for shutting down, HandySwitcher has the ability to let you know about that and waiting for you confirmation to gracefully close them (force them to be closed). This confirmation can be turned ON or OFF through this option, and if OFF, HandySwitcher will gracefully close the non-responding program without warning.

What is “auto switch”?
This is a nice feature for those who like to use the hardware buttons. If this feature is enabled, HandySwitcher will activate the highlighted program in the menu if you keep the highlight on the same entry for the configured amount of time. This means, if you configure HandySwitcher to auto switch after 2 seconds, then while you navigate through HandySwitcher’s menu items if you leave an entry highlighted for more than 2 seconds, HandySwitcher will activate this program. Please note that, when the auto switch features gets activated, if the selected menu item is a program then HandySwitcher will activate it and if the selected menu item is an action then HandySwitcher will execute this action.

Can I change the auto-switch delay?
Yes, the auto-switch delay is configurable, once you activate the feature, you can select the number of seconds (before the auto-switch kicks in) from the drop down list box.

Menu Items

HandySwitcher’s menu shows a list of running programs (except those in the ignore list) and a set of menu items for different actions.
You can enable or disable those menu items through the check boxes in the menu items dialog.

What are the different commands that I can add to the menu?
  • Close All But Active This action closes all the programs running in the background leaving the active program running. (Please note: Programs in the “ignore list”, the “always minimize list” and the “system default list” will not be closed).
  • Close All This action closes all the programs running in the background and foreground. (Please note: Programs in the “ignore list”, the “always minimize list” and the “system default list” will not be closed).
  • Minimize All This action minimizes all the running programs (Showing the today screen).
  • CPU Usage This brings up the “CPU Usage” dialog where you can see a list of all running processes and their CPU usage.
  • Memory Usage This action brings up the “Memory Usage” dialog where you can see a list of running processes and their memory usage.
  • Minimize Active This action minimizes the active program.
  • Close Active This action closes the active program (unless the program was in the “ignore list”, the “always minimize list” and the “system default list”.

Display

Through the display customization dialog, you can customize many areas of HandySwitcher

Change the default interface language.
In the "Display" tab, there is a list of all installed interface languages. Select the language you want from the drop down list box and close the options dialog.

Turn the icons display in the menu on and off
You can tick or un-tick the check box beside the “Show icons in the menu” to enable/disable the showing of icons in the menu.

Custom program icon
You can change HandySwitcher’s icon (the one displayed in the top or bottom bar and usually used to bring HandySwitcher’s menu up). You can achieve this by enabling this feature and providing the full path of your custom icon file. The custom icon file has to be a BMP file 16x16 for QVGA devices and 32x32 for VGA devices. Pure pink RGB(255,0,255) is used as a transparent color.

Change the menu background (skin).
You can select between
  • No image, where HandySwitcher will use your “Menu Colors” settings
  • Theme image, where HandySwitcher will use your theme image as a background.
  • Custom image, where you need to provide your own image to be displayed.
    The supported formats for the menu background are BMP, JPEG, GIF or PNG.
    Please note, if HandySwitcher doesn't display your custom image, then the size your image might be very big, try to use a smaller one instead.
Along with the background image you can also change the colors through the colors dialog.

Menu Items

Icons
By default HandySwitcher displays its icon at the top with the ability to display shortcuts to the other “DinarSoft Handy” products (HandyMenu and HandyLauncher).
Through this dialog you can turn on/off the display of the shortcuts for HandySwitcher, HandyMenu and/or HandyLauncher.
Using the arrows beside each shortcut name, you can move the shortcut in the top bar left or right to the position you like most.

Compact icons display
This is a “shortcut display mode” to save space in the top bar; HandySwitcher can display the shortcuts to HandyMenu and/or HandyLauncher as small arrows below HandySwitcher’s. And by default HandyMenu is displayed to the right and HandyLauncher is displayed to the left; however, you can also reserve this behaviour using the “HandyMenu to the left” option.

Calculate locations from the right.
By default the shortcuts’ positions are calculated from the right so when you switch the orientation the shortcuts will maintain their position relative to the start menu. By enabling this feature, the opposite is used and the shortcuts will maintain their distance from the (OK/Close) button whenever the orientation changes.

Show Icon in the tray bar
By enabling this feature you can have a shortcut to HandySwitcher in the tray bar (bottom bar) and this can be used along or without the top bar icon. Same Tap and tap-and-hold actions are supported on the tray bar icon (as configured in the “Actions” dialog.
