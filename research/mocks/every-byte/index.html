        Glossary

        Plain words for the terms on this map.

        Byte
        Eight bits: one number from 0 to 255. On this plate, one byte is one pixel.
        Paragraph
        16 bytes. Real-mode x86 builds memory addresses from 16-byte steps, so DOS counts memory in paragraphs.
        EXE file
        A DOS program with a header. The header tells DOS how big the program is, where it starts, and which addresses to fix up.
        COM file
        The simplest DOS program. DOS copies the file into memory and starts at its first byte. No header, and at most 64 KB.
        Executable packer
        A tool that compresses a program and adds a small unpacker. When the file starts, the unpacker rebuilds the real program in memory and runs it.
        Literal
        A byte the packer stored as-is. Literals are bytes of the original program.
        Back-reference
        An instruction to the unpacker: copy some bytes it already rebuilt, instead of storing them again.
        Control bits
        16-bit words that the unpacker reads one bit at a time. Each bit helps it decide what comes next: a literal, or a back-reference and its size.
        TSR
        Terminate and Stay Resident. A DOS program that ends but leaves its code in memory, so other programs can use it.
        Assembly
        The readable form of the processor's own instructions. One line, such as mov ax, cs, becomes one instruction.
        Auto-shaping
        Choosing the correct form of each Arabic letter (isolated, initial, medial or final) from the letters next to it.
        Ligature
        Two or more letters drawn as one joined shape. Arabic script uses some ligatures, such as lam with alif.
        VGA
        The IBM PC graphics standard from 1987. Its best-known modes use 16 fixed colours. Those 16 colours are the only colours on this plate.
        BGI
        Borland Graphics Interface. The graphics library that came with Borland's C compilers. Drivers such as EGAVGA.BGI draw on the screen.
        Interrupt
        A numbered call into DOS or the BIOS. A program puts a request in registers and runs, for example, int 21h to ask DOS for a service.
        BCD
        Binary-coded decimal. Each decimal digit is kept in 4 bits, so a program can do exact decimal arithmetic.
        Borland C++ and Turbo C
        C and C++ compilers from Borland International, popular on DOS. Their names are still in the bytes of several of these programs.
        DOSBox and js-dos
        DOSBox emulates a DOS PC. js-dos runs DOSBox in a web browser, so each of these programs can run on this site.
