    ARABART let DOS programs write Arabic on graphics screens, giving each letter the right shape for its place in a word.

    Yasser wrote ARABART in in 1991 and kept improving it until 1993. It loads once and stays in memory as a , so his other programs can call it to draw Arabic in different fonts, colors and styles. Its core trick is : it looks at each letter's neighbors and picks the isolated, initial, medial or final form, the same choice the word at the top of this page makes when you pull it apart. The Demo, the Editor, the Commercial and the Basmallah all draw their Arabic through it.

    ARABART.EXE is an squeezed by an . Its first instructions draw nothing. They move the packed body upward in memory one at a time, then jump into the unpacker that rebuilds the real program.

    Glossary

    Fifteen terms in plain English. Press F1 from anywhere on the page to come back here.

    TSR
    Terminate and Stay Resident. A DOS program that ends but leaves part of itself in memory, so other programs can call it later.
    Assembly
    A language that maps almost one to one onto the processor's own instructions. Programs come out small and fast, but every step is written by hand.
    VGA
    Video Graphics Array, the IBM PC graphics standard from 1987. It gave DOS programs up to 640 by 480 pixels in 16 colors, or 320 by 200 in 256.
    BGI
    Borland Graphics Interface, the graphics library that came with Turbo C and Borland C++. It draws lines, shapes and text on DOS screens.
    Interrupt
    A signal that makes the processor pause, run a short routine, then carry on. DOS programs also ask the system for services through software interrupts.
    COM file
    The simplest DOS program format: raw code and data, loaded as they are into a single 64 KB segment.
    EXE file
    The DOS program format with a header that tells DOS how to load and relocate the program, so it can grow past 64 KB.
    Executable packer
    A tool that compresses a program and puts a small unpacker in front. When the program starts, the unpacker rebuilds the original code in memory.
    Auto-shaping
    Choosing each Arabic letter's form (isolated, initial, medial or final) from the letters beside it, automatically, as text is written.
    Ligature
    Two or more letters drawn as one shape. In Arabic, lam followed by alif becomes لا.
    BCD
    Binary-coded decimal. Each decimal digit gets its own 4 bits, which makes exact decimal arithmetic possible without a math co-processor.
    Borland C++ / Turbo C
    Borland's C and C++ compilers for DOS, each with a full-screen blue editor. Text inside Yasser's programs shows he built them with these tools.
    DOSBox / js-dos
    DOSBox emulates an old PC running DOS. js-dos runs DOSBox inside a web browser, which is how this archive plays the programs.
    Byte
    Eight bits: enough to store one character. All of ARABART.EXE is 11,183 bytes.
    Paragraph
    In real-mode x86, a block of 16 bytes. Segment addresses count in paragraphs, so loaders and packers measure memory in them.
